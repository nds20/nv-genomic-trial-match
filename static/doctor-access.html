Doctor access controls

Verification flow

  1. Admin creates an expiring, single-use invite for a doctor, reviewer, or admin role.
  2. The invite—not the registration form—assigns the role.
  3. The NPI is format-checked and looked up in NPPES; network failure becomes manual review, never automatic approval.
  4. The state license is collected for review by the approving admin.
  5. MFA confirmation is mandatory before approval.
  6. Login requires password + a fresh TOTP code; previously used codes are rejected.

Research integrity

Submissions start as pending_review, edits create retained versions and return reviewed work to the queue, deletes are soft, and mutations are written to an append-only audit table.
